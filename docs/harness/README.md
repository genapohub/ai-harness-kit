# docs/harness · 方法论参考

本目录是 `ai-harness-kit` 的**方法论与工具链参考**，面向所有使用者，随模板一起分发。

## 目录说明

| 子目录 | 内容 | 对使用者的价值 |
|--------|------|----------------|
| `01-调研/` | Harness 调研综述、来源索引、13+1 体系行动启示、五层架构文件分层对照 | 理解「为什么要这么设计」，便于按自己团队情况裁剪 |
| `06-工具链/` | MCP 工具分级、工具治理白名单、同步/自检脚本 | 直接可用的工具治理参考与脚本 |

> 维护者的**自身项目实战记录**（版本迭代日志、项目试点复盘）保留在维护者本地，不随模板分发。

## 怎么用

- 只想要治理骨架：不必读本目录，直接看根目录 `AGENTS.md` / `SECURITY.md` / `project-tracker.md`。
- 想理解设计取舍：先读 `01-调研/00-Harness调研综述.md`。
- 想治理 AI 工具链：参考 `06-工具链/工具治理白名单.md` 与 `MCP-工具分级.md`。

外部项目如果不需要，可以直接删掉整个 `docs/` 目录，不影响治理壳运行。
